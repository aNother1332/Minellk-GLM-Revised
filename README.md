# Minellk ⛏️ — Minecraft 主题连连看（JavaFX 优化版）

> **本仓库是 [Minellk](https://github.com/aNother1332/Minellk)（Java Swing 初始版本）的 JavaFX 重构优化版**：
> 界面整体重设计（Apple 扁平风液态玻璃）、新增无尽生存模式与六种道具、游戏内暂停、弹窗动画与多项性能优化。
>
> 🔗 **版本导航**：原版（Java Swing）→ **[aNother1332/Minellk](https://github.com/aNother1332/Minellk)** ｜ 本仓库（JavaFX 优化版）→ **[aNother1332/Minellk-JavaFX](https://github.com/aNother1332/Minellk-JavaFX)**

> 南方科技大学（SUSTech）2026 年春季学期《计算机程序设计基础》（CS109）课程 PROJECT，原版最终得分 **93 / 100**。

基于 **Java 21 + JavaFX 21** 实现的桌面连连看游戏：方块图标、像素字体与背景音乐均为 Minecraft 风格，在经典连连看规则之上加入了道具、连击计分、账号、防篡改存档与排行榜等完整系统。

## 功能特性

- 🎮 **三种模式**：简单（11×11 棋盘，16 对棋子，100 秒）、困难（12×12 棋盘，50 对棋子，150 秒）、**无尽生存**（消除一对自动补充一对，90 秒内冲击高分）
- ⏸️ **游戏内暂停**：按钮或 ESC 呼出暂停卡片，弹窗打开时自动暂停计时
- 🧰 **六种道具**：钻石镐/斧/铲（点击方块使用，跟随鼠标+旋转特效）、**提示**（高亮一对可消除棋子）、**洗牌**（重排剩余棋子）、**+10 秒**（三种即时道具，点数在实际消耗时扣除）
- 🔗 **经典消除规则**：选中两个相同图案，若连线转弯不超过 2 次且路径畅通即可消除
- ✨ **消除特效**：黄色连线发光展示并淡出 → 棋子放大淡出 → **Minecraft 方块破坏风格的碎裂粒子**（颜色取自方块主色调，带重力/旋转/空气阻力）→ 浮动加分文字，连击时为金色
- 🔨 **道具系统**：钻石镐 / 钻石斧 / 钻石铲，分别对应矿石类 / 木制类 / 土质类方块，可消除对应的单个方块；选中道具后图标会**跟随鼠标移动**，使用时道具在方块处**旋转一周**再破坏方块（碎裂粒子 + 消除音效），点错类别时道具图标会摆动提示且保持选中；**点数在实际消除时才扣除**，再次点击同一道具可收回
- 🎨 **界面**：Apple 风格扁平化设计——浅色液态玻璃面板（白色半透明 HUD、圆角卡片）、系统蓝强调色、玻璃弹窗动画（遮罩淡入 + 卡片缩放淡入，整体同步退场），并**内置 Fusion Pixel 像素字体**（`resource/fonts/`），任何机器上界面都不会退化
- 🔥 **连击计分**：连续消除同种方块触发连击加成（`(连击数-1)×10` 分），并同时奖励道具点数
- 👤 **账号系统**：注册 / 登录 / 游客模式，账号数据持久化于 `users.txt`
- 💾 **存档系统**：胜利、失败或关闭窗口时自动存档；以自定义文本格式保存完整棋盘状态，读取时通过 **MD5 校验和**检测存档是否被篡改
- 🏆 **排行榜**：扫描所有玩家存档，按「分数占比 + 剩余时间占比」加权计算综合分（不同难度有不同系数与满分），取每人历史最佳成绩排名
- 🎨 **双主题皮肤**：自然（nature）/ 村庄（village）两套方块图标，随时更换
- 🔊 **音效与细节**：背景音乐循环播放、消除音效、连击音效、**音量设置（持久化）**、悬停平滑放大、窗口缩放自适应、实时统计、顶部提示信息自动淡出
- ⌨️ **键盘支持**：ESC 暂停/关闭弹窗，Enter 触发弹窗默认按钮
- 🎉 **通关庆祝**：全屏彩屑粒子 + 升级音效后再弹出结算

## 运行方式

环境要求：**JDK 11 及以上**（在 JDK 21 上开发测试）。JavaFX 运行库已随项目附带在 `lib/javafx/`（Windows x64；其他平台请从 [GluonHQ](https://gluonhq.com/products/openjfx/) 下载对应版本替换该目录）。资源文件均以相对路径加载，因此必须在**项目根目录**下运行。

### 一键运行

- Windows：双击 `run.bat`
- Linux / macOS：`./run.sh`（需先 `chmod +x run.sh`）

### 手动命令

```bash
# 编译（源码为 UTF-8 编码）
find src -name "*.java" > sources.txt
javac -encoding UTF-8 --module-path "lib/javafx" --add-modules javafx.controls -d out @sources.txt

# 运行
java --module-path "lib/javafx" --add-modules javafx.controls -cp out app.Main
```

Windows CMD 下可用 `dir /s /b src\*.java > sources.txt` 生成文件列表。

### 在 IntelliJ IDEA 中运行

1. `File → Project Structure → Libraries → +`，将 `lib/javafx` 目录加入模块依赖；
2. 运行配置 `app.Main`，VM options 填入：
   `--module-path lib/javafx --add-modules javafx.controls`；
3. Working directory 设为项目根目录。

> 💡 界面使用 [Fusion Pixel 像素字体](https://github.com/TakWolf/fusion-pixel-font)（`Fusion Pixel 10px Mono zh_hans`）。未安装该字体时游戏会回退到系统默认字体，不影响运行。

## 与课程版（Swing）的主要差异

1. **GUI 全部重写为 JavaFX**：单窗口多场景导航；棋子由「整面板重绘」改为场景图节点，只有变化的节点会被渲染；动画由属性绑定驱动，走 Prism 渲染线程。
2. **流畅度优化**：
   - 悬停放大改为单个棋子的短过渡动画（原版每次鼠标移动都整面板重绘）；
   - 棋子图标在加载期一次性预缩放为 128×128 纹理（原版每次窗口缩放都对 1024×1024 原图重采样）；
   - 特效统一由单个 `AnimationTimer` 按需驱动，无特效时零渲染开销；
   - 死局检测先按图标分组、只在组内配对做 BFS（困难模式最坏情况从约 5000 次 BFS 降到几百次），且道具点数大于 0 时直接跳过扫描。
3. **消除特效**（新增）：连线发光淡出、棋子放大淡出、方块碎裂粒子、浮动加分文字；道具使用时道具图标旋转一周后破坏方块。
4. **模型层与界面解耦**：`Record` 不再依赖界面静态字段，`RecordStore` 校验失败改为返回标记由界面提示，`GameDifficulty` 移入 `model` 包，棋盘生成/深拷贝抽取为 `BoardGenerator`。
5. **一处逻辑修补**：原版用道具消除最后一对棋子时不会触发胜利判定（棋盘清空后游戏卡住），现已在道具消除后补充胜负检查。
6. **道具交互重做**：点数由「选中道具即扣除」改为「实际消除方块时扣除」，点错类别不再白白浪费点数；选中道具后图标跟随鼠标，再次点击同一道具可收回。
7. **界面重设计（Apple 扁平风）**：按钮为蓝底主按钮 / 白底胶囊 / 浅蓝 tinted / 玻璃 / 纯文字五种变体；游戏 HUD 与卡片为浅色液态玻璃；难度、主题、读取存档、排行榜从「切换窗口」改为**主菜单上的卡片弹窗**（遮罩淡入 + 卡片缩放，整体动画）；登录 / 注册窗口为透明圆角；内置像素字体。
8. **规则逻辑抽取**：计分、连击、道具点数经济与死局判定集中在 `model/GameSession`，配套 19 项断言的规则测试，为新模式扩展提供保护。

## 核心算法：连线判定

消除判定在 `utils/Utils.findPath` 中实现，采用**带转弯计数的 BFS**：

- 以「行、列、进入方向」三维数组 `visited[row][col][dir]` 记录访问状态，保证同一格子沿不同方向进入可分别扩展；
- 每个搜索节点记录当前位置、前进方向、已转弯次数与完整路径，转弯超过 2 次即剪枝；
- 只允许经过空格子（终点除外），首次到达终点即返回路径，供 UI 绘制连线。

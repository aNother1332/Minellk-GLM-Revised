# Minellk ⛏️ — Minecraft 主题连连看

> 南方科技大学（SUSTech）2026 年春季学期《计算机程序设计基础》（CS109）课程 PROJECT，最终得分 **93 / 100**。

基于 **Java Swing** 从零实现的桌面连连看游戏：方块图标、像素字体与背景音乐均为 Minecraft 风格，在经典连连看规则之上加入了道具、连击计分、账号、防篡改存档与排行榜等完整系统。

## 功能特性

- 🎮 **双难度模式**：简单（11×11 棋盘，16 对棋子，100 秒）、困难（12×12 棋盘，50 对棋子，150 秒）
- 🔗 **经典消除规则**：选中两个相同图案，若连线转弯不超过 2 次且路径畅通即可消除，附带黄色连线绘制与放大淡出的消除动画
- 🔨 **道具系统**：钻石镐 / 钻石斧 / 钻石铲，消耗道具点数可直接消除对应类别的方块，死局时的救命稻草
- 🔥 **连击计分**：连续消除同种方块触发连击加成（`(连击数-1)×10` 分），并同时奖励道具点数
- 👤 **账号系统**：注册 / 登录 / 游客模式，账号数据持久化于 `users.txt`
- 💾 **存档系统**：胜利、失败或关闭窗口时自动存档；以自定义文本格式保存完整棋盘状态，读取时通过 **MD5 校验和**检测存档是否被篡改
- 🏆 **排行榜**：扫描所有玩家存档，按「分数占比 + 剩余时间占比」加权计算综合分（不同难度有不同系数与满分），取每人历史最佳成绩排名
- 🎨 **双主题皮肤**：自然（nature）/ 村庄（village）两套方块图标，随时更换
- 🔊 **音效与细节**：背景音乐循环播放、消除音效、连击音效、鼠标悬停放大、窗口缩放自适应、倒计时与剩余对数实时显示

## 运行方式

环境要求：**JDK 8 及以上**。资源文件均以相对路径加载，因此必须在**项目根目录**下运行。

```bash
# 编译（源码为 UTF-8 编码）
javac -encoding UTF-8 -d out $(find src -name "*.java")

# 运行
java -cp out app.Main
```

Windows CMD 下编译可用 `dir /s /b src\*.java > sources.txt` 生成文件列表后 `javac -encoding UTF-8 -d out @sources.txt`。

也可以直接在 IntelliJ IDEA 中打开本项目运行 `src/app/Main.java`，项目已附带 jar 打包配置（`src/META-INF/MANIFEST.MF`，Main-Class: `app.Main`）。

> 💡 界面使用 [Fusion Pixel 像素字体](https://github.com/TakWolf/fusion-pixel-font)（`Fusion Pixel 10px Mono zh_hans`）。未安装该字体时游戏会回退到系统默认字体，不影响运行。

```
src/

```

## 核心算法：连线判定

消除判定在 `utils/Utils.findPath` 中实现，采用**带转弯计数的 BFS**：

- 以「行、列、进入方向」三维数组 `visited[row][col][dir]` 记录访问状态，保证同一格子沿不同方向进入可分别扩展；
- 每个搜索节点记录当前位置、前进方向、已转弯次数与完整路径，转弯超过 2 次即剪枝；
- 只允许经过空格子（终点除外），首次到达终点即返回最短路径，供 UI 绘制连线。

死局检测会遍历棋盘上所有剩余棋子两两配对调用该算法，若不存在任何可消除对且道具点数为 0，则判定失败。
